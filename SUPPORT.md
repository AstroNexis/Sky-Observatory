# support

## where to get help

- **bug reports** -- open an issue on [github](https://github.com/astronexis/sky-observatory/issues)
- **feature requests** -- open an issue with the "enhancement" label
- **questions** -- start a discussion on [github discussions](https://github.com/astronexis/sky-observatory/discussions)
- **security issues** -- see [security.md](security.md)

## before you ask

- check the [readme](readme.md) and [contributing](contributing.md) guides
- look through existing issues to see if someone already asked
- make sure you're on the latest version

## response times

this is a side project, so responses might take a few days (or weeks).
we'll do our best to get back to you, but please be patient.

# security policy

## reporting a vulnerability

if you find a security issue in sky vault, please don't open a public issue.
instead, send an email to **phucan@tutamail.com** with as much detail as
you can provide.

we'll try to get back to you within a week. once the issue is confirmed, we'll
work on a fix and release it as soon as possible. we'll also credit you in the
release notes if you'd like.

## what we'd like to see

- a description of the vulnerability
- steps to reproduce it
- the version or commit you found it in
- any potential impact

## supported versions

| version | supported          |
|---------|--------------------|
| latest  | :white_check_mark: |
| older   | :x:                |

we only patch the latest release. if you're on an older version, please
upgrade first.
